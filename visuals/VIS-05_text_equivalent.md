> **Rubric Architect: Quick-Reference Guide to Correction and Justification**
>

>
> A 4-phase left-to-right flowchart covering: Phase 1 Operational Workflow
> (claim one criterion at a time, Prompt Hierarchy: System Prompt over User Tips,
> QA and submit); Phase 2 Core Logic (Atomic criteria are binary Pass/Fail;
> Stacked criteria produce false evaluations -- decompose into Atomic units);
> Phase 3 Correction and Justification Formatting (Three-Part Entry: Action,
> Corrected Criteria, One-Sentence Justification); Phase 4 Quality Filter
> (criteria must be gradable as binary True/False, no subjective language).
> Common Errors table: Subjective, Open-Ended, Over-Specific, Process-Oriented.
